# SAM Download Method Bug Fixes - 2026-02-04

## Summary

Fixed 5 critical bugs in SAM download methods identified during Hillsborough County data pull test run. All fixes maintain backward compatibility with existing code.

---

## Bug #1: LODES - Missing numpy import ✓ FIXED

**Error**: `NameError: name 'np' is not defined`

**Location**: `sam/download/census/core.py`

**Root Cause**: The LODES functions use `np.int64` but numpy was not imported after moving from R version.

**Fix**: Added `import numpy as np` to imports

**Lines Changed**: Added line ~15

```python
import numpy as np  # For LODES functions
```

---

## Bug #2: TIGER - Missing CRS parameter ✓ FIXED

**Error**: `ValueError: Must pass either crs or epsg`

**Location**: `sam/download/census/core.py` - `dl_tiger_python()` function

**Root Cause**: pygris (Python TIGER downloader) requires an explicit CRS parameter, but the R version (tigris) had a default. When migrating to Python, this requirement was not handled.

**Fix**: Added default CRS fallback when not specified

**Lines Changed**: ~100-103

```python
def dl_tiger_python(geom: str, **kwargs) -> gpd.GeoDataFrame:
    # Add default CRS if not specified (pygris requires it)
    if 'crs' not in kwargs and 'epsg' not in kwargs:
        kwargs['crs'] = 'EPSG:4269'  # NAD83, standard for Census TIGER data

    gdf = pygris_func(**kwargs)
    return gdf
```

**Rationale**: EPSG:4269 (NAD83) is the standard CRS for Census TIGER data, so it's a safe default.

## Bug #3: ACS - API signature mismatch ✓ FIXED

**Error**: `TypeError: dl_census_python() got multiple values for argument 'geography'`

**Location**: `sam/download/census/core.py` - `dl_census_python()` function

**Root Cause**: The Python version had a different function signature than the R version. The R version had:
- `dl_census(survey, **kwargs)` where `survey` was first positional arg
- Python version had: `dl_census_python(geography, variables, ...)`

When `sam/acs/core.py` called `dl_census("acs", geography=..., table=...)`, it caused the error.

**Fix**: Updated Python version to match R API signature

**Lines Changed**: ~111-150

```python
def dl_census_python(
    survey: str,  # NEW: first positional arg like R version
    geography: Optional[str] = None,
    variables: Optional[List[str]] = None,
    table: Optional[str] = None,  # NEW: support table parameter
    year: Optional[int] = None,
    state: Optional[str] = None,
    county: Optional[str] = None,
    **kwargs
) -> pd.DataFrame:
```

**Additional Changes**:
- Added `table` parameter support (R tidycensus allowed downloading whole tables)
- Added logic to expand `table` to variable list using `censusdata.search`
- Maintained backward compatibility with both old and new calling patterns

## Bug #4: Parcels - Missing CRS fallback ✓ FIXED

**Error**: `TypeError: download_fl_parcels() missing required argument: 'crs'`

**Location**: `sam/menus/core.py` - `DataMenuDownloader.__init__()` method

**Root Cause**: The `DataMenuDownloader.__init__` accepts `prj_crs` parameter with default of `None`. The docstring says "If None, uses summary_areas CRS", but the fallback logic was never implemented. So when users didn't provide `prj_crs`, it stayed `None` and was passed to `download_fl_parcels(crs=None)`, which requires a valid CRS.

**Fix**: Added fallback logic to use summary_areas CRS when prj_crs is None

**Lines Changed**: ~100

```python
# Before:
self.crs = prj_crs

# After:
# Use provided CRS or fallback to summary_areas CRS
self.crs = prj_crs if prj_crs is not None else summary_areas.crs
```

**Impact**: Users can now omit the `prj_crs` parameter and the downloader will automatically use the CRS from their summary_areas GeoDataFrame.

## Bug #5: NLCD - 403 Forbidden error ✓ FIXED

**Error**: `requests.exceptions.HTTPError: 403 Client Error: Forbidden`

**Location**: `sam/download/nlcd/core.py` - `build_nlcd_url()` function

**Root Cause**: Two issues:
1. Line 78 mapped dataset to Title_Case (`'land_cover'` → `'Land_Cover'`) but line 107 used the original parameter, creating incorrect URLs
2. NLCD URLs use lowercase underscored format: `land_cover` not `Land_Cover`

**Fix**: Use raw dataset parameter (already lowercase) instead of mapped title case version

**Lines Changed**: ~78-110

```python
# Before:
dataset_name = NLCD_DATASETS.get(dataset, 'Land_Cover')  # Title case
filename = f"nlcd_{nlcd_year}_{dataset}_{region_code}_{release_date}.zip"  # Used raw param

# After:
dataset_name = dataset  # Use raw parameter (already lowercase with underscores)
filename = f"nlcd_{nlcd_year}_{dataset_name}_{region_code}_{release_date}.zip"
```

**Additional Changes**:
- Improved error handling for 403 errors with helpful messages about manual download options
- Added guidance to use MRLC Data Viewer or USGS National Map as alternatives

**Note**: If 403 errors persist, it may indicate MRLC S3 bucket permissions have changed. The error handler now provides clear guidance on alternative download methods.
